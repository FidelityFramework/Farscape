# HelloWayland Project

## Purpose
Intentionally naive native Wayland window demo — parallel to WrenHello in form/function.
Displays an SVG-rasterized image (Clef logo) with a "shimmer" animation effect
(skeleton-loading style from JS web frameworks).

## Architecture: 11-Step Pipeline
1. Wayland display connection
2. DRM render node (`/dev/dri/renderD128` — Strix Halo iGPU)
3. GBM buffer allocation (640x480 ARGB8888)
4. DMA-BUF export as file descriptor
5. HIP runtime init + device setup
6. SVG rasterization via resvg (Clef logo)
7. DMA-BUF import to Wayland compositor
8. xdg_toplevel window creation
9. Buffer attach + commit (zero-copy presentation)
10. Event loop dispatch
11. Clean shutdown

## Available Binding Libraries (All Generated by Farscape)

### Fidelity.Platform CPU/Linux/x86_64
Sub-libraries with individual fidproj files:
- **Fidelity.Libc** (14 .clef) — dlopen/dlsym, mmap/malloc, open/close/read/write/ioctl, socket, string
- **Fidelity.Wayland** (16 .clef) — Core, Protocol, XdgShell, DmaBuf; 15 listener struct builders
- **Fidelity.DRM** (8 .clef) — Core + Mode/KMS
- **Fidelity.GBM** (4 .clef) — device, buffer, surface management
- **Fidelity.Pthread** (8 .clef) — thread, mutex, cond, attr

### Fidelity.Image CPU/Linux/x86_64
- **Fidelity.Image.Resvg** (4 .clef) — SVG parse/render, EnumErrorCode convention
- **Fidelity.Image.Stb** (4 .clef) — image loading (not used by HelloWayland)

### Fidelity.Platform GPU/AMD/RDNA3_5/StrixHalo_iGPU
- **HIP Runtime** (19 .clef) — Device, Memory, Stream, Module, Error; EnumErrorCode convention
