# Farscape Binding Architecture

## CRITICAL: This is NOT P/Invoke
Farscape generates for FNCS/Firefly native compilation:
- `FidelityExtern`, not `[<DllImport>]`
- Function bodies are `Unchecked.defaultof<T>` stubs that Alex replaces with MLIR
- No Marshal, no BCL dependencies
- PSG → Alex → MLIR → LLVM → native binary

## Two-Layer Model

### Layer 1: Platform.Bindings (exists today)
Raw extern stubs generated by FidelityCodeGenerator:
```fsharp
module Fidelity.libc.IO
let write (fd: int32) (buf: nativeint) (count: nativeint) : int64 =
    Unchecked.defaultof<int64>
```

### Layer 2: Idiomatic F# Wrappers (future work)
Safe functional APIs that call Platform.Bindings:
- C error codes → Result types (voption semantics, stack-allocated)
- Raw pointers → typed nativeptr with lengths
- Resource pairs (malloc/free) → disposable patterns
- const char* → NativeStr (UTF-8 length-prefixed)
- All wrappers compile to zero-overhead native code via type erasure

## Moya Feature (completed)
- Namespace grouping by C function prefix patterns
- TOML project files (.moya.toml) for scoped generation
- CLI: `moya analyze`, `moya init`, `project --project`
- FSharp.SystemCommandLine v2.1 pipeline API

## FNCS Type System
- int → NTUint (platform word), size_t → NTUsize
- Strings are UTF-8 fat pointers (ptr + len), not .NET UTF-16
- Option/Result are stack-allocated tagged structs
- Memory regions (Stack, Arena, Peripheral) tracked at type level
